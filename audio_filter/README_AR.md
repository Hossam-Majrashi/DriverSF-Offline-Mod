# فلتر الصوت المحلي — السياسة الثانية

مصدر أداة كتم انتقائي لـWwise v48 وإزالة صوت فيديو BIKi. هذا فلتر منفصل عن
قائمة DLL. النسخة المنشورة على GitHub **لا تتضمن ملفات اللعبة أو الجرد
المستخرج أو الخطة المحضرة أو بيانات الاسترجاع**؛ لا تعمل أوامر التفعيل مباشرة
من clone نظيف، ولا يُدَّعى توفر إعداد استخراج عام مكتمل داخل هذا المستودع.

## السياسة الحالية

- تحديد الموسيقى من تصنيف Music ومراجع MusicTrack الفعلية، وليس من وجود
  المؤثر في حزمة واحدة مع الموسيقى.
- كتم الحوار ذي وسم متحدث نسائي. يُستخدم حقل المتحدث الأخير قبل الأرقام؛
  ذكر امرأة في سياق الحوار لا يكتم رد شخصية رجل.
- **إبقاء أصوات التصادم والواجهة والمشاة والبيئة والسيارات والتسجيلات غير
  المحسومة دون كتم تلقائي.** التسجيل غير الموسوم قد يحتاج مراجعة إذا ظهر
  فيه صوت غير مرغوب فيه؛ لا يُدَّعى اكتمال تصنيف كل المتحدثين بالاستماع.
- سياسة الفيديو الحالية تزيل كل مساراته الصوتية، بما فيها الحوار الرجالي
  والمؤثرات الممزوجة؛ ليست فصلًا دقيقًا لكل متحدث. الصورة والتوقيت محفوظان.

على تثبيت التطوير المحلي، حُددت 122 قطعة موسيقى و42,920 قطعة حوار موسومة
بمتحدث نسائي، وأُعيدت 485 قطعة مؤثرات و37 حوارًا غير محسوم بعد إزالة الكتم
الاحترازي الواسع. **هذه إحصاءات تثبيت بعينه، وليست ضمانًا لكل إصدار لعبة.**

## الاستخدام المحلي

يحتاج الإعداد جردًا متوافقًا في مجلد شقيق للعبة اسمه `DSF_Audio`، يتضمن
`manifest.json` وملفات `native/` و`banks/` المستخرجة. أدوات استخراج ذلك الجرد
ليست موزعة هنا. لا تعاود التحضير فوق خطة موجودة ولا تنسخ خطة جهاز آخر.

مدير الفلتر يعتمد على Python 3 وLinux (`fcntl` و`/proc`). أغلق اللعبة قبل
التطبيق أو الاسترجاع. من مجلد اللعبة، لتثبيت محضر سلفًا فقط:

```bash
python3 mod/audio_filter/manage.py status
python3 mod/audio_filter/manage.py verify
python3 mod/audio_filter/manage.py restore
python3 mod/audio_filter/manage.py apply
```

`restore` يعيد حالة ما قبل الفلتر الصوتي مع إبقاء التعديلات المرئية السابقة.
`apply` يعيد السياسة الثانية الضيقة المحضرة. أي بصمة غير معروفة توقف العملية؛
لا تتجاوز ذلك بالكتابة العمياء فوق تعديل آخر. استرجع الصوت أولًا قبل تغيير
فلتر صور/فيديو سابق بُني الصوت على حالته.

البيانات **المحلية الخاصة، غير المنشورة**:

- `plan.json`, `state.json`, `selection.csv`؛ تصف هذا التثبيت وحده.
- `prepared/`؛ ملفات اللعبة المحضرة، وليست كودًا صالحًا للنشر.
- `mod/backups/audio_filter_v1/original/`؛ أصول الاسترجاع، لا تحذفها إذا احتجتها.
- تقارير التحقق والفهارس ومعاينات المتصفح والسجلات؛ قابلة لإعادة الإنشاء.

**حذف النسخ والخطة وبيانات التحضير يلغي إمكانية الاسترجاع أو إعادة التطبيق
بهذه الأدوات.** تظل تعديلات ملفات اللعبة المثبتة كما هي؛ استرجاعها حينئذ يحتاج
مصدرًا أصليًا آخر أو تحقق ملفات اللعبة. يمكن للسجلات والكاش أن تعود أثناء
التشغيل والاختبارات؛ تستبعدها `.gitignore` وأداة تصدير نسخة GitHub.

## الطريقة والقيود

لا تُحذف الأحداث والحزم ولا تُصفّر بايتات Vorbis المضغوطة عشوائيًا. يُخفض
Volume وLFE للعقد المحددة مع إبقاء التوقيت والمراجع، وتُصفّر بيانات PCM/IMA
المختارة بصيغة صالحة. تُفحص بنية الحزم وتُرفض نسخ غير معروفة.
في BIK يعاد بناء جدول الإطارات دون مسارات الصوت مع إبقاء حزم الصورة مطابقة.

إبقاء البنية والمدد يقلل خطر تعطيل المهمات، لكنه لا يعادل اختبار تقدم كل
مهمة أو إثبات غياب كل صوت غير مرغوب فيه أثناء المزج الحي. لا ضمان صوتي مطلقًا
من الوسوم وحدها. جرّب التصادم والقوائم واستعراض السيارات وحوارًا ومشهدًا بعد
التطبيق، واسترجع عند حدوث خلل.

## الاختبارات

```bash
# اختبارات مستقلة بملفات مؤقتة، لا تعدّل اللعبة:
python3 audio_filter/test_manage.py
```

أدوات التدقيق التفصيلية وتقارير فك الترميز وصور المتصفح الخاصة بمرحلة التطوير
ليست مواد نشر ولا تُضمّن هنا. اختبارات الوحدة المتاحة لا تعادل تجربة الصوت
أو تقدم المهمات داخل اللعبة.

ملفات WAV/WEM في مكتبة الاستماع، إذا احتفظت بها محليًا، أصول تاريخية قد تحتوي
الأصوات المكتومة في اللعبة. بيان `filter_status.js` يحدّث واجهة المكتبة عند
التطبيق والاسترجاع؛ أعد تحميل الصفحة. فتح الأصل مباشرة خارج الفهرس يشغله كما هو.
