# فلتر الأصول المرئية المحلي

أدوات منفصلة عن DLL لمعالجة صور ومجسمات مختارة في نسخة المستخدم من اللعبة.
المصدر والاختبارات وقائمة الاختيار فقط مواد نشر؛ ملفات البدائل والأرشيفات
المحضرة والخطط والنسخ الاحتياطية وصور المراجعات ليست ضمن المستودع.

## النطاق

تحدد `selection.json` الصور والمواد/الأجزاء المختارة. البدائل تُستخرج محليًا
من أصول اللعبة، ويجب أن تتطابق صيغة DDS والأبعاد والضغط والمستويات والأحجام.
تُخفى المثلثات المحددة بجعل فهارسها متطابقة، دون تغيير أحجام الأرشيفات أو
معرفات الموارد. لا يُلغى منطق الشخصيات أو تصادمها أو تحريكها، وليس هذا
استبدالًا عامًا لكل الشخصيات بأشخاص آخرين. المواد المشتركة قد تمنع تعميم الإخفاء.

يوجد [ملحق مستقل لفيديوهات مقدمات المهمات](README_VIDEOS_AR.md). هذا الملحق
يغير صورة الفيديو ويحافظ على صوته؛ فلتر الصوت المنفصل قد يكتم الصوت لاحقًا.
لا يعني أي منهما اكتمال إزالة كل ظهور أو نجاح كل مهمة.

## متطلبات التحضير

تعتمد أدوات الإدارة الحالية على Python 3 وLinux (`fcntl` و`/proc`). يلزم
جرد DSF_Assets متوافق مع الأرشيفات وملفات DDS المشار إليها، وnumpy للتحضير
واختبارات الهندسة. أدوات الاستخراج الكاملة والجرد الخاص غير موزعة هنا؛
**ليس هذا فلترًا جاهزًا للتفعيل فور تنزيل GitHub.** لا تستخدم خطة جهاز آخر
أو تعتبر تطابق Driver.exe وحده دليلًا على تطابق بقية ملفات اللعبة.

للمطور الذي يملك الجرد الصحيح محليًا، ومن مجلد اللعبة:

```bash
python3 mod/asset_filter/manage.py prepare --manifest /path/to/private/DSF_Assets/manifest.json
```

هذا إعداد محلي، وليس تعليمات استخراج مكتملة. يرفض التحضير خطة أو نسخًا
سابقة موجودة؛ لا تحذفها لتجاوز رسالة تعارض أو تطبق الخطة على نسخة معدلة
مختلفة دون التحقق من كل البصمات.

## إدارة تثبيت محضّر

احفظ وأغلق اللعبة قبل التفعيل أو الاسترجاع. من مجلد اللعبة:

```bash
python3 mod/asset_filter/manage.py verify
python3 mod/asset_filter/manage.py restore
python3 mod/asset_filter/manage.py apply
```

الأوامر تحتاج خطة محلية و`payloads/` و`prepared/` ونسخ الاسترجاع. ليست هذه
الملفات قابلة للنشر لأنها تتضمن بيانات لعبة أو تخص تثبيتًا بعينه. إذا حذفتها
فلن تعمل عمليات الاسترجاع/إعادة التفعيل بهذه الأدوات؛ تظل الأصول المثبتة معدلة
حتى تعيدها من مصدر أصلي آخر أو تتحقق من ملفات اللعبة.

يرفض المدير البصمات المجهولة والتعديلات المختلطة، ويستبدل الملفات المحضرة
بشكل متحقق منه بدل ترقيع نسخة غير معروفة. لا تتجاوز الرفض بالكتابة العمياء.
استرجع فلتر الصوت أولًا إذا كان مبنيًا على حالة هذه الأصول قبل تغيير الفلتر.

## الحدود والاختبار

الفلتر ثابت على القرص. إزالة DLL أو إيقاف خيارات القائمة أو `--vanilla` لا
يسترجعه. صحة البنية والبايتات لا تضمن صحة الرسم أو نجاح جميع المهمات؛ جرّب
الواجهة والمشاة ومهمة متأثرة، واسترجع عند حدوث خلل إذا كنت تملك أصول الاسترجاع.

اختبارات الوحدة تستخدم ملفات مؤقتة ومحاكاة ولا تعدل اللعبة:

```bash
python3 asset_filter/test_manage.py
python3 asset_filter/test_video_filter.py
```

ملفات السجلات والتقارير والمعاينات قابلة للحذف وليست متطلبات تشغيل. راجع
`../PUBLISHING_AR.md` لتصدير الكود والتبعيات المسموح بنشرها فقط.
